## 安装

1. 解压本包。在你要使用的桌面版 MT5 中点 **文件 → 打开数据文件夹**。
2. 把所需 `.ex5` 复制到 **MQL5 → Indicators**。`.mq5` 是可编辑源码，可以一起保存。
3. 回到 MT5，在 **导航器 → 指标** 右键 **刷新**，再把指标拖入图表。未出现时重启 MT5。
4. 先用默认参数查看；同时查看两种 MACD 时保持同一品种、同一图表周期及 12 / 26 / 9。

这是图表指标，不需要开启算法交易或 DLL 导入。ZeroLag MACD 的本机收盘交叉弹窗默认关闭，可在参数里开启。成品尚未安装到你的交易终端数据文件夹。

## 布林带 + RSI

你的 `Bollinger Bands.txt` 实际是 ChartArt 的 Pine 策略。移植版保留指标计算及条件提示：

- 中轨为 **SMA(close, 200)**，上下轨为中轨 ± **2 倍总体标准差**。
- RSI 为 **6 周期 Wilder 平滑**，多空交叉阈值都是 **50**。
- 买箭头：同一根已收盘 K 线，RSI 上穿 50，且收盘价上穿下轨。
- 卖箭头：同一根已收盘 K 线，RSI 下穿 50，且收盘价下穿上轨。

原始挂单、撤单及成交模拟没有转成自动交易功能；箭头是条件成立位置，不能当成成交记录。最新 K 线的带线和颜色会变化，箭头等待收盘。

原源码的 K 线/背景着色条件没有判断 RSI 数值：空头是“前收盘高于本根上轨、本收盘回到上轨下、中轨下降”；多头对称使用下轨和中轨上升。因此颜色与买卖箭头可以不同。MT5 使用彩色 K 线和背景矩形，填充没有复制 Pine 的透明混色；背景默认保留最近 500 根。

## SMA 与 EMA

SMA 默认周期为 **20 / 50 / 100 / 150 / 200 / 250 / 300 / 400 / 500 / 600**。各线可单独修改周期、价格源和显示开关。前五条在 close ≥ SMA 时蓝色，否则橙色；后五条为绿色/红色。颜色始终比较图表 close，即使均线价格源改成 high 等也一样。

EMA 默认周期为 **20 / 50 / 100 / 200**，颜色依次红、橙、青、蓝，全部使用 close。EMA 从已加载历史的首个 close 开始递推；左端预热不足时不显示。历史起点不同可能造成开头数值与 TradingView 有差别。

## 两种 MACD 与 Stoch RSI

**新 MACD 默认是 DEMA(12) − DEMA(26)，信号线 EMA(9)；CM 则是 EMA(12) − EMA(26)，信号线 SMA(9)。** 两者不能直接当作相同信号。具体公式、配色、同公式验证和合成行情比较见 [MACD 比较说明](MACD_比较说明.md)。

CM 可选择当前或更高周期。高周期仅映射已完成的源 K 线，例如 M5 图上 11:00 起才使用 10:00–11:00 的 H1 最终数值；默认交叉圆点再等待当前图表 K 线收盘。这里没有复制旧 Pine `security()` 的历史前视行为。不能选择低于图表的周期。

Stoch RSI 使用 MT5 `iRSI(close,14)`，将最近 14 根 RSI 归一化到 0–100，再做 3 根 SMA 得到 K、3 根 SMA 得到 D。蓝色 K、橙色 D，参考线 20 / 50 / 80。RSI 区间宽度为零时约定 Raw=0。最新未收盘 K 线会实时变化。

## SMC 源码移植

依据最新 `smc.txt` 中完整的 LuxAlgo SMC 源码移植，保留作者署名和原许可。最终算法与安全确认差异以 [SMC 规则与数据接口](SMC_规则与数据接口.md) 为准，不与先前的独立草稿混用。

- 内部结构默认确认长度 5、大结构 50；采用源码的方向段切换确认方式。
- 包含 BOS / CHoCH、内部及大结构 OB、EQH / EQL、FVG、Strong / Weak 高低点、Premium / Discount 及日周月高低点选项。
- 收盘确认和高周期映射采用安全实现，避免提前读取未完成 K 线的最终高低价。与原 Pine 的确认时机及部分异常边界处理有明确差别，详见规则文档。

可按需要关闭部分结构或区域，减少图表拥挤。改变参数、补载更早历史或改变初始化范围，可能改变结构状态。

## GSM SNR 与 SND

两份手册都是图示规则，未提供现成代码。程序按手册的逻辑实现，区域宽度、明显反弹、长影线、盘整和强推动等主观描述采用可调数值；这些数值是程序默认值，不冒称教材指定。

SNR 至少等待两次相互分离的确认反应才画区，收盘穿越外边界时翻转支撑/阻力角色；区分主要/次要区域，识别穿插差区、影线刺穿后收回，以及默认 3 根内快速收回的假突破。反弹和到区提示只确认已收盘 K 线，不执行限价单。

SND 按长影线、盘整突破、连续强推动起点识别区域，并跟踪第一次回踩。宽区域的 50% 中位是参考价格，不是自动下单指令。手册“30 pt”的单位通过参数设定，不应直接混同经纪商报价小数位。详见 [SNR 规则与数据接口](SNR_规则与数据接口.md) 和 [SND 规则与数据接口](SND_规则与数据接口.md)。

## Volume Profile

默认最近 **200 根、200 层、68% 价值区域**，使用 Tick Volume；可切换真实成交量及阳线/阴线过滤。真实成交量为零时不混入 Tick Volume，不凭空生成 POC。

原源码把每根 K 线的**全部成交量重复加到该 K 线覆盖的每一层价格**。本版保留这个算法，结果是价格层活动权重，不能解释为真实逐笔成交量分布。POC 是权重最大层；最大值相同时取较低层。价值区域从 POC 向邻层扩展，平局先向上；两侧都是零时停止，因此实际覆盖比例可能低于设定的 68%。

可见范围模式使用图表实际可见 K 线，最多 3000 根；原 Pine 以时间跨度估算，口径有差异。右侧距离在本版用像素控制，原文件用未来 K 线数量。图表缩放后会刷新。

数据接口只提供**最新一根上的区间快照**，旧 K 线 buffer 留空。可见范围或区间变化会改变这个快照，不能把当前 POC 回当成过去已知的交易信号。

## EA 读取接口

以下编号从 0 开始。读取确认信号用 shift 1；对 `EMPTY_VALUE` 先做缺失值判断。Volume Profile 按上一节只读 shift 0 快照。

| 指标 | Buffer | 含义 |
|---|---|---|
| BB + RSI | 0 / 1 / 2；5 / 6；12；13 | 中/上/下轨；买/卖箭头价格；RSI；着色方向 +1/-1/0 |
| SMA 10 | 0,2,…,18 | 十条 SMA；后接的奇数编号为颜色索引 |
| EMA 4 | 0 / 1 / 2 / 3 | 四条显示线 |
| ZeroLag MACD | 0 / 1 / 2；4 | MACD / Signal / Hist；收盘交叉 +1/-1/0 |
| CM MACD | 0 / 2 / 3；5；7 | MACD / Signal / Hist；圆点价格；交叉 +1/-1/0 |
| Stoch RSI | 0 / 1 | K / D |
| Volume Profile | 0 / 1 / 2；3 / 4；5 / 6 | POC / VAH / VAL；重复权重合计/输入量；实际 VA%/样本根数 |
| SMC / SNR / SND | 见规则文档 | 各自状态、区域边界及确认事件 |

默认调用可写 `iCustom(_Symbol,_Period,"指标文件名")`。若覆盖 BB/SMA/EMA 参数，本次编译版本的 `input group` 在位置参数中占字符串槽；应按源码和随包验证脚本中的实际顺序传参。直接拖图表无需处理这些槽位。隐藏开关是否保留数值因指标而异：SMA/EMA 隐藏后相应显示 buffer 留空；CM 保留数据。
