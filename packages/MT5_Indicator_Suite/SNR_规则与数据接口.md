# GSM SNR 指标：教材规则与数据接口

本指标依据用户提供的 GSM 支撑阻力教材第3–9页实现。教材给出视觉规则，没有指定 ATR 倍数、摆动窗口、等待根数等数值。以下数值都是可调的工程定义，不能写成教材原定阈值。

## 教材页码对应

| 教材页 | 原规则 | MT5 实现 |
|---|---|---|
| 第3页 | 同一区域至少触碰两次，画矩形区；画好后等待下次机会 | 两个分离的严格摆动触点，各有已确认离区反应后成区；第一个触点锁定价格边界；成区本身不发到区/买卖箭头 |
| 第4页 | 阻力突破后转支撑，支撑跌破后转阻力 | 已收盘 close 严格穿越远端边界后翻转角色；突破当根不再重复计为新角色的回测 |
| 第5页 | 多次触碰为主要区，少数触碰为次要区 | 默认2次确认反应为次要、3次及以上为主要；次数只在独立访问后有合格反弹时增加 |
| 第6页 | 明显反弹为好区，长期穿插为坏区 | 默认20根观察窗内两侧收盘交叉达到3次，或到区后反弹等待超时，标为差区；默认隐藏差区 |
| 第7页 | 影线穿过但收盘关回，或突破后迅速关回原区，为假突破；等待收盘 | 同根影线穿远端后收回发假突破；另支持收盘突破后默认3根内关回原区域，恢复原角色；旧突破事件留在原历史位置 |
| 第8页 | 价格到区才等待机会，不追价 | 单独输出到区掩码；远离区域或成区当根不产生到区事件。反弹/假突破箭头是已收盘条件提示，不是挂单、成交或自动交易 |
| 第9页 | 两触最低门槛、到区、收盘、反应的总检查表 | 通过独立手工场景分别验证形成、触碰、确认、翻转及过滤，不以盈利回测代替这些规则检查 |

## 工程量化默认值

- 严格摆动左右各3根。相同高/低点不算严格摆动；第 p 根触点须等到第 p+3 根收盘后才知道，最早在下一根开始时发布确认结果。
- ATR采用14周期Wilder平滑。首区半宽为首触点ATR的0.15，至少2个point；之后不随ATR、第二次触点或翻转重新扩大。
- 每个初始触点必须在右侧确认窗口内，至少有一次收盘离开该触点所测区域达到0.50倍该触点ATR。两个初始触点至少相隔6根；第二触点价格须位于第一候选的冻结边界内。
- 成区后的访问以K线 high/low与区域相交为到区。一次持续访问只累计一次反应；反弹距离用**访问发生前一根**的ATR锁定，须收盘离开近端边界达到0.50倍该ATR。
- 反弹等待默认允许访问当根至其后第6根（`b-visit<=6`）；到第7根仍未达到距离，标为停滞差区。不是把连续6根相交都当成6次触碰。
- 完整离开区域后才允许下一次访问。假突破恢复当根也不算第二次新访问；若收回时仍在区域内，须先离区才能再次累计反应。
- 默认3次反应为主要区；20根内两侧收盘交叉达到3次为穿插差区。收盘在区内时不增加两侧交叉计数。
- 同根假突破：支撑 low<下边界但close>=下边界（前close也在下边界之上/相等）；阻力对称。区域角色不因影线单独改变。
- 追加参数 `InpFalseReturnBars=3`：收盘先突破后，在随后1至3根已收盘K线内，只要支撑原区域的close>=原下边界，或阻力原区域的close<=原上边界，即可视为迅速关回。只收在原区内部也可恢复角色，不要求穿越整区。设0关闭跨K线关回，仅保留同根影线判断。超过窗口后按普通收盘突破/翻转继续处理。
- 默认区域最多保留1500根，回放最多3000根，最多30个区域（包含隐藏候选）。这些是计算/显示管理设置，历史加载起点与配置会影响可用区集合；不保证缺少历史时与另一平台完全一致。
- 默认显示主要及次要好区域，差区隐藏但继续跟踪；反弹和穿插情况改变后质量可更新。

## 第7页覆盖补充

原初稿只覆盖同根影线假突破。按教材“突破后又迅速关回”的多K线图例，已在输入末尾添加 `InpFalseReturnBars`，保留原21个输入位置。每区记录最新突破的原角色和突破bar，在时限内回到原区域时恢复该角色并发假突破掩码；不会回改历史突破事件，也不会同时重复发普通翻转和新访问事件。恢复后绘图从恢复被确认的时间开始，原区价格边界继续冻结。

## 缓冲区

| Buffer | 内容 |
|---:|---|
| 0 / 1 | 当前最近可显示支撑区上/下边界 |
| 2 / 3 | 当前最近可显示阻力区上/下边界 |
| 4 / 5 | 对应支撑/阻力的累计确认反应次数 |
| 6 | 已确认事件位掩码，见下表 |
| 7 / 8 | 多/空拒绝条件箭头的图表价格；无条件为EMPTY_VALUE |
| 9 | Wilder ATR；当前未收盘bar输出上一根已收盘ATR |
| 10 | 仍保留的已成形区域数量，包含因差区或主次显示过滤而隐藏的区域 |
| 11 / 12 | 对应可显示支撑/阻力的质量：1好、0差；对应区域被隐藏/不存在时EMPTY_VALUE |
| 13 | 到区位掩码：1支撑、2阻力，可组合为3；差区到区不发该掩码 |

| Buffer 6 bit | 含义 |
|---:|---|
| 1 / 2 | 新支撑/新阻力完成第二次初始确认反应并成区 |
| 4 / 8 | 收盘突破后转为支撑/转为阻力 |
| 16 / 32 | 开始一次支撑/阻力访问（差区也可跟踪） |
| 64 / 128 | 支撑/阻力访问后满足反弹距离，反应次数增加 |
| 256 / 512 | 向下/向上假突破；同根影线或跨bar快速关回均使用此事件 |

多个区域在一根上发生不同事件时位掩码可以组合。箭头只提示条件，不代表成交价。EA读取时应使用shift=1及更新事件管理；当前shift=0只继承上一根区域快照，事件/到区掩码为0，箭头为空。区域对象是当前保留区域及其当前角色的展示；历史审计使用逐bar缓冲区，不能把当前矩形向历史推当作当时已知信号。

## 独立测试脚本

独立验证脚本的17个测试组全部通过（包括真实指标对象与截图检查），使用11个唯一名称的自建合成品种；严格检查K线数量，避免历史数据残留影响结果。新建品种无需删除空历史；同名自建品种仅对已确认存在的旧测试数据进行清理。

手工主场景：首触点p30、第二触点p50、翼长3，成区事件在已收盘b53、b54开始可知。ATR30=75/14；冻结下界99.196428571429，上界100.803571428571。b60开始访问，b63反弹成主要区；连续b61–65不重复开始访问；b67下影假突破，b70收盘支撑转阻力，b71上影假突破，b74（隔4根、已过快速关回窗口）普通阻力转支撑；b82累计第3次两侧交叉变差。另有独立超时、反应不足、间隔不足、同低点、不改历史前缀、未来扰动、未收盘扰动、append-vs-fresh与多bar关回镜像场景。
