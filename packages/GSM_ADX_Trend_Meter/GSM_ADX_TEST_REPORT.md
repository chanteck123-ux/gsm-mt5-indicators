# GSM ADX 真实测试报告

测试日期：2026-09-08 至 2026-09-09（马来西亚时间）。这是独立指标的工程验证，没有开平仓和交易收益测试。

## 成品与环境

正式指标及随包 Compare、读取示例实际由 **MetaEditor 5.0.0.6140** 编译，均为 **0 errors、0 warnings**。正式源码 SHA256：`dd9d9843faec00000b9a02ebf039da1373ff7a885061280ad0faf4f7e41b1d96`。EX5 和其他文件哈希见交付清单。

默认算法 Wilder、周期 14；另提供 MT5 普通 ADX 和用户新附件 Pine ADX and DI。前两个算法分别对照自己的内置来源，Pine 模式单独验证原始递推公式。

真实行情测试使用桌面 `terminal64.exe` 对应的 **build 6140** 隔离副本及已有保存登录，服务器 FxPro-MT5 Demo，实际黄金名称为 **GOLD**。合成行情测试使用工作目录内 **build 6182** 隔离终端，人工创建 M1 品种，禁止交易。测试脚本不调用下单或账户信息 API；终端可有服务器连接。没有修改用户现有 EA、SOP 或原交易终端指标。

## 规则、增量与数据故障

规则测试从正式源码提取实际规则函数，配合手写期望结果，覆盖附件要求的 20/25/40 等值、19→26 同根双阈值、高位继续上升、41→43→42 确认位置、双向 DI 交叉、ADX 下降过滤、低于 25 的可选过滤、站稳／增强首次进入、等值 DI 和缠绕窗口、预热 EMPTY 与真实零值，并覆盖自定义 15/22/35 阈值及未来扰动。提取规则块 SHA256：`c786f48530d353be40167b504b6036d133af8de98b89c84b0f1eda019c615a82`。

工程测试在固定 2026-03-02 起点的合成 M1 数据中，每种内置算法从 80 根逐根追加到 200 根，**各核对 251100 个已收盘缓冲区值**，全部一致；每步 3～14 号 shift 0 均为空。8 次当前柱 OHLC 改变时，实时曲线会变，旧确认值保持不变。还对照更深 40 根历史补载后的同一起点、周期 2/7/10/30、显示／提醒开关、阈值变更和有效零值。

5 类无效输入均出现正式指标的中文 OnInit 失败日志，见 [原生初始化错误摘录](evidence/invalid_input_native_log.txt)。MT5 可能先返回句柄再异步初始化，因此测试保留句柄等待初始化，并核对未产生计算数据和对应原生日志；不只凭句柄是否立即 INVALID 判断。

受控注入保留真实 `iADX/iADXWilder` 后端，仅在测试副本代理 API 返回值：让第三条 CopyBuffer 报告少复制一项，或 BarsCalculated 报告暂未就绪。验证最新待处理位置统一为空、面板可用状态关闭、已处理时间不提前推进；同柱后续报价恢复时与正式原版的 15 个缓冲区一致。转换清单记录正式源码及测试副本哈希。**注入副本不是交付指标，不能安装到正式 Indicators/GSM 中。**

## Pine ADX and DI

独立参考使用附件的 TR/DM 递推和、DI、DX，并在每一根重新扫描最近 N 个有效 DX 求 SMA，周期测 **14、2、7、30**。每周期 180 根、540 个三线值，最大绝对误差不超过 **7.11×10⁻¹⁴**。

每周期从 80 到 180 根做 100 次追加，核对 194250 个已收盘接口值完全一致；另测未来扰动、显示／提醒开关、4 次当前 OHLC 改变。第一轮 14 周期在终端账户切换附近发生测试行情写入失败；完善选中品种和 IO 重试后，以相同正式源码和同样精确断言重跑通过，没有放宽数值条件。

原始首根与 0 比较的初始化会产生特殊结果：正价完全平直历史可得到 +DI=100、ADX=100；本版忠实保留该首根效应，不将其解释为真实可交易趋势。有效 ADX=0 和 DI 分母为零导致 ADX 不可用也分别实际验证。

**未测试：**“已完成 SMA 预热后出现 DX 的 NA，再恢复”的原生过渡夹具。1300 根平价递推在本机保留次正规非零浮点数，没有成功产生预期的后续 DX 缺口；该段三线数值仍与参考一致，但不能声称验证了并未出现的过渡。固定 Max bars 窗口移除最早柱而平台不触发历史重置的特殊情形也未单独验证。

## 复核方式

正式 Compare 可在桌面 MT5 Scripts 中运行，默认读取 GOLD／XAUUSD 候选名称和另一品种；根据实际经纪商品种名修改输入。所有结果写入该终端 `MQL5/Files`，以实际生成的新文件为准。

`evidence` 保存验证源码、独立参考、编译日志、CSV、截图和模板。合成验证需要独立终端及允许创建自定义品种；故障注入必须先从正式源码重新生成并编译到专用 `GSM_TEST`，不可覆盖正式指标。文件生成器中开发目录路径应按复核环境调整。没有把账户配置、凭据或终端网络日志放入交付包。
