## 边界与历史一致性

| 项目 | 状态 | 实际覆盖 |
|---|---|---|
| 默认暖机 | 通过 | VFI 旧序索引 0～258 为 EMPTY，首个有效值为 259；SMA(3) 后首个有效位置为 261 |
| 前均量不含本根 | 通过 | 手算前均量 100，本根量 1000，倍数 2.5，截量与正流量均为 250 |
| length=1 与 EMA=1 | 通过 | 上述手算点 VFI=2.5、EMA=2.5、差值=0 |
| 严格价格门槛 | 通过 | 变化恰好为 ±cutoff 时流量为 0，严格超过后才记正／负截量 |
| 有效零值 | 通过 | 平价且成交量有效、零截量倍数、零本根流量分别验证；未把所有零值丢弃 |
| Real Volume 不回退 | 通过 | Real 全零但 Tick 非零，VFI 仍为 EMPTY |
| NaN、无穷、非正典型价格 | 通过 helper 层检查 | 直接调用实际生产 helper；不是对经纪商异常 OHLC 的全链路注入测试 |
| 成交量中途为零后恢复 | 通过 | 公开 VFI／Signal／Histogram 在分母不可用时 EMPTY，恢复后与保留内部 EMA 状态的独立期望一致 |
| 显示开关不改接口 | 通过 | 所有数据集分别建立可见和关闭绘图实例，已收盘 0～9 缓冲区一致 |
| 未来扰动及前缀 | 通过 | 前 159 根已收盘柱 ×10 缓冲区，分别与改变后续行情和截短历史的实例一致，共 3,180 项比较 |
| 当前柱增量更新 | 通过 | 真实 `CustomTicksAdd` 修改当前柱；旧句柄增量结果与参数不同但计算设置相同的新实例全量结果一致；之前的已收盘输出未变 |
| 新柱移动与时间对齐 | 通过 | 再加入下一根报价，之前全部 520 根 ×10 缓冲区保留对应值，没有错位 |
| 原生图表 | 通过 | 实际载入生产 EX5，生成并检查双线、差值柱及零轴截图 |

“前缀与未来扰动”是固定历史前缀的整体比对；没有将其夸大为对全部可能路径的穷尽测试。当前柱及新柱检查各使用受控报价步骤，不能替代长时间报价压力测试。
