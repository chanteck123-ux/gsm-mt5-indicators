# PVO 与价格方向组合｜研究说明

日期：2026-10-03

状态：**研究规则说明**。当前仅保存逻辑与验证要求；不代表已经新增 PVO MT5 指标、不代表已经接入 EA，也不代表已经通过黄金策略回测。

## 1. PVO 是什么

PVO（Percentage Volume Oscillator，百分比成交量振荡器）比较短周期与长周期成交量均线的差异，常见形式为：

```text
PVO = 100 × (FastVolumeMA - SlowVolumeMA) / SlowVolumeMA
```

因此：

- PVO 上升：近期成交/活动相对长期基准增强。
- PVO 下降：近期成交/活动相对长期基准减弱。
- PVO > 0：短周期成交量均线高于长周期成交量均线。
- PVO < 0：短周期成交量均线低于长周期成交量均线。

**重要：PVO 本身不判断买盘或卖盘方向。** 它反映的是成交/活动强弱变化。方向必须由价格、结构或其他方向性条件提供。

在 MT5 外汇/黄金环境中，还必须区分 `tick_volume` 与 `real_volume`。若经纪商没有可靠的真实成交量，则 PVO 可能基于 Tick Volume；这代表报价活动强弱，不等同于交易所完整真实成交量。

## 2. 价格 + PVO 四种组合

### A. 价格上涨 + PVO 上涨

研究解释：

- 价格向上，同时市场活动增强。
- 上涨得到更强的成交/活动参与支持。
- 可视为“上涨较有力”的确认信号之一。

注意：

- PVO 仍不能单独证明后续一定继续上涨。
- PVO 从负值区上升，与 PVO 已在正值区继续上升，含义强度不能完全视为相同，应同时记录零轴位置。

### B. 价格下跌 + PVO 上涨

研究解释：

- 价格向下，同时市场活动增强。
- 下跌过程有更多市场参与。
- 可视为“下跌较有力”的确认信号之一。

注意：

- 不能把 PVO 上涨直接解释成“卖盘成交量增加”，因为 PVO 不区分买卖方向。
- 正确说法是：**价格方向向下，而整体成交/活动增强，因此下跌走势得到更强参与度支持。**

### C. 价格上涨 + PVO 下跌

研究解释：

- 价格仍在上涨，但成交/活动参与度减弱。
- 上涨动力可能减弱。
- 需要留意回调、横盘或假突破。

这是一种“价格与参与度背离”的研究信号，但不能单独作为做空条件。

### D. 价格下跌 + PVO 下跌

研究解释：

- 价格仍在下跌，但成交/活动参与度减弱。
- 下跌动力可能衰减。
- 需要留意止跌、横盘或反弹。

这是一种“下跌仍在继续，但参与度下降”的研究信号，不能单独作为做多条件。

## 3. 简化记法

```text
价格方向 = 市场现在往哪里走
PVO方向 = 这个价格移动背后的成交/活动参与是在增强还是减弱
```

研究上的四格简表：

| 价格 | PVO | 研究解释 |
|---|---|---|
| 涨 | 涨 | 上涨参与增强，上涨较有力 |
| 跌 | 涨 | 下跌参与增强，下跌较有力 |
| 涨 | 跌 | 上涨参与减弱，留意回调/横盘 |
| 跌 | 跌 | 下跌参与减弱，留意反弹/横盘 |

## 4. EA 研究使用边界

PVO **不能单独作为买卖条件**。若后续接入黄金 EA 候选，应至少结合：

- 支撑／阻力或 SND／SMC 结构；
- EMA 趋势与价格方向；
- K 线或既有触发规则；
- PVO 零轴位置；
- 必要时比较 PVO 本身、PVO 斜率，以及信号线/柱值的增量贡献。

默认优先使用已收盘 K 线数据，避免用当前未收盘柱的 PVO 变化制造前视式确认。

## 5. 后续验证要求

若正式加入指标库或 EA 决策路径，必须另外登记：

1. PVO 快周期、慢周期、信号周期；
2. 使用 SMA/EMA 等哪一种成交量均线；
3. 数据源是 Tick Volume 还是 Real Volume；
4. 读取 buffer、shift 和 EMPTY_VALUE 规则；
5. 价格方向如何定义（单根涨跌、EMA斜率、结构趋势等）；
6. 原策略 vs 加 PVO 的独立增量对照；
7. 净利润 USD、最大权益回撤金额/百分比、PF、交易数、胜率、平均盈亏、成本；
8. Real Tick、滑点/成本压力与样本外测试。

只有在相同资金、行情、时间、仓位及成本条件下比较后，才能判断 PVO 是否真的改善黄金 EA，而不是只让历史图表看起来更合理。
