## 自主维护

每次研究开始先读当前状态、按提交更新新增文件和分支；结束后记录实际结论与下一步。目录归属、命名和阅读顺序自行安排。新的自有仓库在当前连接确实可访问后自动纳入下一次盘点，不能声称已经读取未连接的仓库或整个 GitHub。

仓库外部参考只登记出处与允许使用的知识。私有目录、教材和测试资料维持原有范围，不向公开仓库复制。
